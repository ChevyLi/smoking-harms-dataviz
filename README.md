# 烟·账 — 吸烟危害数据可视化

一个基于 WHO、国家卫健委、中国疾控中心官方数据的创意数据叙事页面。用 ECharts 把冰冷的数字变成可感知的生命账本。

## 在线预览

> GitHub Pages 地址将在部署后填入。

## 页面内容

| 章节 | 主题 | 可视化 |
|---|---|---|
| 01 成分账 | 7000+ 种化学物质、69 种致癌物、20+ 种相关癌症 | 漏斗图、对数对比条形图 |
| 02 生命账 | 全球年死 700 万+、二手烟 160 万+、中国 100 万+ | 实时死亡计数器、规模对照图 |
| 03 中国账 | 2019 年归因死亡 227 万+（肿瘤/心血管/呼吸） | 南丁格尔玫瑰图、占比图 |
| 04 人群账 | 3 亿吸烟者中 2.96 亿为男性 | 横向对比条形图 |
| 05 孩子账 | 中学生二手烟暴露率 29.4% / 47.6% | 双仪表盘、百人象形图 |
| 06 数据溯源 | 15 条带官方链接的原始数据 | 可点击核查表格 |

## 数据来源

- 世界卫生组织（WHO）— 世界无烟日 2019、Tobacco fact sheet 2026
- 国家卫生健康委员会 — 《中国吸烟危害健康报告 2020》
- 中国疾控中心慢病中心 / China CDC Weekly — 吸烟归因死亡研究、青少年二手烟暴露研究

所有条目在页面的「数据溯源」章节中均列出原文链接，可逐条核查。

## 本地运行

单文件自包含，直接双击 `index.html` 即可打开，无需联网或本地服务器（ECharts 已内嵌）。

如需本地服务器：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 声明

数据保留原文表述（"超过 / 至少 / 以上"）。不同统计年份与口径的数据不可直接相加。本项目仅用于数据可视化课程作业与公益宣传。
